## Overzicht

Op deze pagina vergelijk je verzekeringspremies van verschillende maatschappijen, per categorie:

- **Motor** (`/vergelijkingen/motor`)
- **Reis** (`/vergelijkingen/reis`)
- **Woon** (`/vergelijkingen/woon`)
- **Leven** (`/vergelijkingen/leven`)

:::caution[In ontwikkeling]
Deze pagina toont momenteel nog geen live data. Zodra de bijbehorende server-endpoint (`/api/vergelijking/{type}`) klaar is, wordt hier een vergelijkingstabel getoond met actuele premies per maatschappij. De onderstaande beschrijving geeft de bedoelde werking weer.
:::

## Wat kun je hier doen?

- **Een categorie kiezen** — via de URL (bijv. `/vergelijkingen/motor`) navigeer je naar de vergelijking voor die verzekeringssoort.
- **Premies vergelijken** — zodra de koppeling actief is, zie je hier een tabel met premies per maatschappij voor de gekozen categorie.
