## Overzicht

Op deze pagina zie je een overzicht van de verzekeringsmaatschappijen in het systeem, met per maatschappij de naam, het adres, e-mailadres en telefoonnummer.

:::caution[In ontwikkeling]
Deze pagina toont momenteel nog voorbeelddata. De koppeling met echte data en beheerfunctionaliteit (toevoegen, bewerken, verwijderen) moet nog gebouwd worden. De onderstaande beschrijving geeft de bedoelde werking weer.
:::

## Wat kun je hier doen?

- **Maatschappijen bekijken** — een tabel met per maatschappij:
  - Naam
  - Adres
  - E-mailadres
  - Telefoonnummer
