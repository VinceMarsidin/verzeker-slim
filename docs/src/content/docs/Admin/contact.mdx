## Overzicht

Op deze pagina kunnen bezoekers een bericht sturen via een contactformulier.

## Een bericht versturen

1. Vul de volgende velden in:
   - **Naam** *(verplicht)*
   - **E-mailadres** *(verplicht)* — moet een geldig e-mailadres zijn
   - **Bericht** *(verplicht)*
2. Klik op **Versturen**.

Na het versturen verschijnt een bevestiging dat het bericht is ontvangen. Bij een ongeldig e-mailadres of een leeg verplicht veld toont het formulier een foutmelding, zodat je de gegevens kunt corrigeren.

## Wat gebeurt er met het bericht?

Verzonden berichten komen terecht bij de beheerders van het systeem, die ze kunnen inzien via het admin-dashboard (zie [Contact berichten](/dashboard/contact) in het beheerdersgedeelte).
